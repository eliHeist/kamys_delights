# Photo shot list

Drop images into `src/lib/assets/photos/` using the **exact slot name** below (`.jpg`, `.png`, `.webp` or `.avif`).
They are picked up automatically and converted to responsive AVIF/WebP at build time. Any slot without a
file shows a branded placeholder, so the site always looks finished.

Tips: export at ~2400px on the long edge, warm natural light, real people where possible (Ugandan context),
leave some calm space in the frame. Stock is fine for launch; swap in Kamy's own photos as they come.
